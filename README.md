# Посетители
В университете на входе регистрируется в течение дня время прихода и ухода каждого посетителя (ЧЧ:ММ). 

Таким образом, за день получены N пар значений, где первое значение в паре показывает время прихода посетителя и второе значение – время его ухода. 

Найти промежуток времени, в течение которого в университете одновременно находилось максимальное число посетителей. Если таких промежутков несколько, то вывести информацию о первом их них.

Имя файла с записями задано в командной строке. 

## Формат файла
В первой строке записано число записей (N) в файле.

Во второй строке и далее записаны пары значений: `время_прихода время_ухода`.

Время записано в формате `ЧЧ:ММ`.


## Вывод
Вывести в консоль строку с количеством посетителей, началом промежутка времени, концом промежутка времени, записанных через пробел.

## Пример
Входной файл:
```
7
09:10 12:15
09:00 10:00
10:00 12:00
11:00 11:59
11:10 13:00
12:10 14:15
09:20 14:15
```
Вывод: `5 11:10 11:59`

## Требования
Программа не должна использовать контейнеры STL (std::vector, std::string и т. д.).
